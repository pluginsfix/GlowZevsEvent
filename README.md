# GlowZevsEvent

Плагин динамического трехстадийного события «Гнев Зевса» для серверов Minecraft (Paper 1.21, Java 21).

## Описание механики

Событие проходит в 3 стадии:
- **Стадия 1**: Падение молний, разрушение определенных блоков, безопасная зона (PvP выключено, урон от падения отключен).
- **Стадия 2**: Небесный дроп (SkyDrop), продолжение ударов молний, доступ к сундукам.
- **Стадия 3**: Спавн сундуков Зевса с маскировкой предметов и задержкой на сбор лута (cooldown), включение PvP.

## Команды и права

- `/glowzevsevent start` — принудительный запуск события (`glowzevsevent.admin`)
- `/glowzevsevent stop` — остановка активного события и очистка локации (`glowzevsevent.admin`)
- `/glowzevsevent add <lightning|chest|skydrop> <шанс>` — добавление предмета из руки в таблицу дропа (`glowzevsevent.admin`)
- `/glowzevsevent reload` — перезагрузка файлов конфигурации и сообщений (`glowzevsevent.admin`)

## Зависимости

- WorldGuard (опционально, для управления флагами региона)
- WorldEdit / FastAsyncWorldEdit (опционально, для вставки и очистки схематики корабля)
- DecentHolograms (опционально, для голограмм над сундуками; при отсутствии используется встроенный провайдер)
- PlaceholderAPI (опционально, для поддержки плейсхолдеров в сообщениях и действиях)
